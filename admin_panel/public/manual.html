Timing Studio Guide

Quick reference manual for synchronizing transcripts, mapping timestamps, and using shortcut hotkeys.

01 The Syncing Workflow

The Timing Studio allows you to align audio tracks with prayer text stanzas, generating synchronized subtitles (LRC format) for the mobile app.

1

Import Text

Click **Import** in the top bar. Paste the raw stanzas (one line per verse) and apply them to load the text slots.

2

Record Timestamps

Click **Record**. As you listen, press Enter (when cursor is focused in input) or click the line row when each line begins. The active line will capture the timing stamp and jump to the next input block.

3

Refine Segments

If you miss a stamp, enter start/end times in the **Redo range** panel, then click **Record range** to retake only that specific segment.

02 Keyboard Shortcuts

Shortcuts adjust depending on whether you are editing lyric text or controlling the audio playback.

Editing Mode Active

When the typing cursor is inside a lyric text input field:

Save stamp & move down Enter
Play / Pause audio (prevents typing space) Space
Insert a space character in text Shift / Ctrl + Space
Navigate to previous input ↑ Arrow
Navigate to next input ↓ Arrow
Create new line (on last line) Enter

Control Mode Active

When no text field is focused (focus on background/body):

Start editing active line input Enter
Stamp current playhead time & move down Enter
Play / Pause audio Space
Rewind 2 seconds ← Arrow
Forward 2 seconds → Arrow
Rewind 5 seconds Shift + ← Arrow
Forward 5 seconds Shift + → Arrow
Undo previous timing stamp (if recording) Backspace

03 Auto-Saves & Backups

The studio backs up your timing progress to protect against page refreshes or connection drops.

✓

Debounced Auto-Saves

Every edit automatically triggers a debounced save to localStorage after 2 seconds of inactivity. If the window closes, reopening will present a banner to **Resume** your work.

💾

Downloadable Backups

Click the **↓ Draft** button at the top right to download your current stanzas and timing timestamps immediately as a .json file.
